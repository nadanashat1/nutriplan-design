# NutriPlan - Food, Nutrition & Fitness Planner

A nutrition and meal planning app built with vanilla JavaScript. It fetches real meal and nutrition data from external APIs and lets the user browse meals, check nutrition facts, and keep a personal food log.

## Features

- Meal browsing and search powered by TheMealDB API
- Nutrition lookup through a dedicated nutrition service
- Product data through a product service
- Personal food log held in client-side state
- Client-side routing without a framework
- Modular architecture: API services, state management, and UI rendering in separate layers

## Tech stack

- Vanilla JavaScript (ES modules)
- HTML5, CSS3
- TheMealDB API and nutrition/product APIs

## Getting started

Serve the folder with any static server (for example `npx serve .`) and open `index.html`.
